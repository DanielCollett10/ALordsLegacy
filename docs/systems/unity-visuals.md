# Unity visuals

**Purpose:** draw Sim state with no rules of its own. Every drawn thing reads a Sim registry, rebuilds when that registry's
`Version` changes, and gets its art from a `VisualDefinition` by id (decisions 0002, 0008, 0009, 0016, 0020).

## Key types and files

`Assets/Game/Visuals/` (`LordsLegacy.Game.Visuals`), `Assets/Game/Lighting/`.

| Type | Role |
|---|---|
| `InstancedDraw` | Shared `Graphics.RenderMeshInstanced` helper, batches of 1023. Used by trees, people, modules, log piles, camp and construction. |
| `TreeRenderer` | Standing trees from `TreeRegistry`, grouped in 64 m cells, frustum-culled. Also stumps and felled trunks. |
| `PeopleRenderer` | Citizens (adult or child, by age; a stock carrier holds a food crate) and oxen. Lerps `PreviousX/Z` → `X/Z` by `TickFraction` (current while paused). Yaw from `FacingRad`. Citizens that arrive or leave appear and vanish with their ids; phase state of removed citizens is dropped (T-509). |
| `WalkBob` | Placeholder walk bob. Rate depends on metres walked per tick and `ViewSettings.WalkStepsPerMetre`. |
| `CampRenderer` | Tents, fire, log pile and tie post from `World.Camp`. One tent per Homeless family; nothing once the camp is removed (CMP-23). Rebuilds on footprint, camp, family or `Homes.Version` changes. |
| `ModuleRenderer` | Woodcutting modules, forager huts, houses (`visual.module.house`) and standalone structures (granary, hewing station, sawpit, storage yard), stretched to the footprint. Market stalls, with food crates by fill. Beam stacks beside hewing stations and plank stacks beside sawpits, height by `StackFill` (T-526). Skips unbuilt footprints. |
| `BushRenderer` | Forage bushes from `BushRegistry`, instanced. Rebuilds only on `Bushes.Version` (not on reservations). |
| `LogPileRenderer` | One log per ledger log in every location. Piles and stockpile stack at their point; storages along the footprint's X; ox carriers drag logs behind the ox. |
| `ConstructionRenderer` | Scaffold per unbuilt site, height from `ConstructionProgress.Fraction`. |
| `RoadRenderer` | One mesh per `RoadSegment`, rebuilt on `RoadNetwork.Version`. Preview mesh red where `InvalidRanges` apply. |
| `AreaRenderer` | Fill and outline per area, from the flattened polygon. Work areas dashed (`WorkAreaRenderer`, shown only while the operation panel is open). Market areas get stall slot outlines (`StallGrid`). |
| `PlacementOverlay` | While a placing tool is active, outlines every plot, marks its corners as snap points and draws pile circles (PL-12, PL-15). |
| `TerrainDrape` | Shared ground helper: `Point`, `Ribbon` (polyline, at most 1 m steps), `Fill` (triangles, at most 2 m). Lifts above terrain. |
| `GroundOverlay` | `Material(texture)` from shader `LordsLegacy/GroundOverlay` (unlit, alpha, depth bias with distance). Cached material. |
| `VisualRegistry` | `VisualRegistry.asset`. `TryGet(id)`, `Get(id)` (logs an error, returns a placeholder). `IsPlaceholder`. |
| `VisualDefinition` | Mesh and materials for one id. |
| `VisualSizes` | Box sizes for placeholder art, including the hewing station, sawpit, storage yard, beam and plank stacks. |
| `CursorMarker` | Ground cursor at the snapped point: a 0.6 m sphere for areas (AR-20) or a road-width ring for roads (RD-18). The tool shows or hides it (PL-06). |
| `SelectionRing` | Ring under the selected agent. |
| `SunLightModel` | Pure maths: `GameTime` + `Daylight` → elevation, azimuth, colour, intensity. |
| `SunLightController` | Writes the model to the directional light and ambient in `LateUpdate`. Steady light is `ViewSettings.SteadyLight`. |

## Rules

- No GameObjects or colliders per tree, agent, or log. Use `InstancedDraw`.
- Ground visuals use `TerrainDrape` and `GroundOverlay`. Renderers fall back to `Sprites/Default` only if the shader is missing.
- Visual ids are written into Sim data as strings (`visual.tree.generic`, `visual.road.dirt_path`, `visual.module.woodcutting_hut`).
  Sim data holds only the id.
- Placeholder art is generated by `PlaceholderVisualGenerator`, which is idempotent. Swap art by editing the definition.

## Extending

1. Pick the registry the thing comes from and rebuild on its `Version`.
2. Add a visual id and a `VisualDefinition` (generator or by hand).
3. Use `InstancedDraw` for many small things, or a mesh renderer for big per-segment things.
4. Wire the component in `GameSceneGenerator`.

## Gotchas

- Lerp by `SimHost.TickFraction`. Paused, the current position is drawn.
- `TreeRenderer` must not rebuild every frame. It rebuilds only on `TreeRegistry.Version`.
- Materials are cached. Do not destroy them.
- Unity Terrain is only drawn. Sim heights come from `World.Terrain`.
