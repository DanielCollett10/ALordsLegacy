# GDD amendments (live)

The GDD in `source/` stays as written (v0.4). This file records owner decisions made since.
**Where this file and the GDD disagree, this file wins.** Rule IDs refer to the GDD;
new rules use `-A` suffixes. Technical decisions are in `docs/decisions/`.

## Project

- **3D from the start.** No 2D view phase. The mockups show UI layout only.
- **Test map:** the MVP 2×2 km map is a placeholder generated by an editor script (seeded
  heightmap of rolling hills, valleys, plains, plus a forest region). Hand-authored maps
  (WORLD-01) come later. Map data reaches the Sim through a bake step (decision 0003).
- **Population scale:** the full game targets **5,000–10,000 citizens** in total across all
  villages: big towns, not just hamlets (replaces tech spec PRF-02's 500). Performance work
  is measured against 10,000.
- **Managing a big settlement:** systems are mostly set-and-forget (a farming area stays a
  farming area); the player's job at scale is spotting and fixing bottlenecks. UI for
  finding bottlenecks matters more than per-building micromanagement. (DECIDED direction)
- **Combat:** large Total War-style battles are a long-term **goal, not a milestone**. They
  come only after all core city-builder systems work. Don't design MVP systems around them,
  but don't rule them out either (PRIN-08 style).
- **Namespaces:** the project template's namespace is removed and replaced by `LordsLegacy.Sim` /
  `LordsLegacy.Game` (not "Legacy", which reads as "legacy code").

## Time (TIME, CLK)

- Units: durations in game minutes, speeds in m per game minute (decision 0004).
- Calendar: 365 days, game starts 1 March, Year 1, 06:00. Seasons are meteorological:
  Spring Mar–May, Summer Jun–Aug, Autumn Sep–Nov, Winter Dec–Feb. Top bar shows
  e.g. `14 Mar · Spring · Year 1 · 08:40`. (PROPOSED)
  > Implementation note: the top bar also shows the weekday first, e.g. `Sun 14 Mar · Spring · Year 1 · 08:40`
  > (`GameTime.Format`). The weekday matters for the Sunday rest rule (FOOD-A4). Owner to confirm the format.
- Days per year and game minutes per real second are tuning values, not code. (DECIDED)
- Year rollover: the year number increments on 1 January; Year 1 is a short year starting
  1 Mar. DayOfYear is counted from 1 Jan (1 Mar = day 60). No leap years. (DECIDED)

### Weekly allotment and larders (replaces ECO-03's single village deduction)

The week has a day of rest (Sunday). Once a week each household fetches a week of food
and then eats from its own larder every day. This gives shortages a visible shape and a
weekly rhythm of village life.

| FOOD-A4b | **Future mechanic (not in scope now):** the day of rest needs a church. Without one, the village is still small and villagers keep working seven days a week. With church access they rest on Sunday (and later gain happiness) | DECIDED (future) |
| FOOD-A5 | Every house has a **larder** (a food inventory location, LED-01 "house store"). Homeless families at the camp-site have a camp larder each | DECIDED |
