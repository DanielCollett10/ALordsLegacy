# M12: Fixes: build tool, deconstruction, saves

**Shipped (player-visible):** a new game starts with **40 logs**. The Woodcutter build entry is greyed out ("Needs 8 logs
(have N)") until affordable. The area and its modules are drafted as ghosts with a running cost; **Confirm** places all of
it in one go, **Cancel** discards the draft. **Expand modules** adds modules later. Any built module can be **Deconstructed**
for half its logs, and a whole operation at once; cancel is offered while it runs. An operation area with modules cannot be
deleted ("Deconstruct its buildings first"). The Load list has a bin icon per save (shared confirm dialog) and greys out
saves this build cannot read.

**Design sources:** `design/building-tool.md` (BT-01..22), `construction.md` (CN-50..58), `saving.md` (SV-23, SV-34),
`camp.md` (CMP-06). Technical shape: decisions 0037, 0038, 0039.

## Technical changes by system

- **Start and config:** `StartLayout` stock is 40 logs (T-383). `SimConfig` synced to M12 Sim defaults (T-400).
- **Build cost:** `BuildCost` pure queries: `MinimumFor(type)` (8 for woodcutting), `Of(modules)`, `CanAfford` (T-384).
- **Draft and batch commands:** `DraftModulePlacement` checks previews against polygon and ghosts (T-385).
  `DesignateOperation` (all or nothing, T-386) and `PlaceModules` (Expand, T-387) run inside one `Apply`.
- **Deconstruction:** `DeconstructionRegistry`, `DeconstructionWork`, `Mark`/`Cancel`/`DeconstructOperation` commands,
  `task.deconstruct` as helpers-only heavy work (T-393..395). `DeleteArea` refuses an area with modules.
- **Tuning:** `DeconstructTimeShare` and `DeconstructRefundShare` (both 0.5) in `SimTuning`, saved in Core.
- **Save:** Structures section holds deconstruction entries and pending operations. `SaveWriter.CurrentVersion` is 4
  (1 at M11), bumped per change (decision 0038).
- **Unity tools:** `OperationDraft` (plain state) and `OperationDraftTool` (input, palette, ghosts, one command on Confirm)
  (T-389, T-390). Expand starts the same tool at the module stage (T-392). `ModuleTool` removed.
- **UI:** build bar re-checks cost each frame (T-388). Tool panel gates Confirm on `CanConfirm` (T-391). Shared
  `ConfirmDialog` (UI Toolkit, own UIDocument) for the operation panel and Load list (T-396). Operation panel has Expand,
  per-module and whole-operation Deconstruct (T-392, T-397). `SaveStore.Delete` and greyed unreadable saves (T-398,
  T-436, T-437). `GameSceneGenerator` wires the panels; `Game.unity` regenerated.

## Decisions

- 0037: an operation and its modules are placed by one command; the draft lives only in the Unity tool.
- 0038: every change to saved bytes bumps the save format version in the same task.
- 0039: deconstruction marks a built module, a task finishes it; the refund is one unowned pile at the site.
- Owner decisions (design docs): CMP-06 40 logs; CN-53 half the build minutes; CN-56 hut deconstruct unassigns families;
  SV-23 delete with confirm; SV-34 greyed old saves.

## Known gaps and debt

- **Placeholder numbers:** deconstruct shares (CN-53, CN-54) and build recipes (CN-02) are PLACEHOLDER/PROPOSED.
- **No walk to site:** builders and deconstructors work where they stand (CN-23, carried from M10).
- **Cost gate only on the woodcutter:** BT-03 waits for the house and granary entries.
- **Unknown-map saves not greyed:** only a version refusal greys a row. A save from another map is refused at Load (SV-30).
- **Reader text:** `SaveReader` says "Unknown save format version N" (not SV-33 wording). The Load list shows SV-34 text.
- **Deconstruct only in the operation panel:** the house panel (CN-50, HM-21) is M13.
- **Test evidence:** Sim 1311 passed (`test-runs/M12-T-401.md`). Unity counts not recorded; T-402 play check not written up.
